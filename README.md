# Rhode Island: law as git history

Work in progress. This repository will hold the law of Rhode Island as a git history: one file per provision, one commit per
change, `git blame` and `git log` working line by line.

Planned first build: the Rhode Island Constitution and core titles of the General Laws, text only

Source: [Rhode Island General Assembly (rilegislature.gov)](https://webserver.rilegislature.gov/Statutes/).
